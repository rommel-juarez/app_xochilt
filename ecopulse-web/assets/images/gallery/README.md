Las imágenes de la galería en `index.html` se cargan actualmente por URL
desde Unsplash (con `alt` descriptivo en cada una). Coloca aquí tus propias
fotografías optimizadas (WebP o JPG, ancho recomendado 800–1200px) y
actualiza las rutas `src` correspondientes en `index.html` para servirlas
localmente.
